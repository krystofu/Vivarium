# VIVARIUM PULSE 0.1.0 — LoreBary Test Packet

## Goal

Prove that PULSE earns one of six LoreBary plugin slots. The plugin should create a large, reliable improvement in interpersonal chemistry and relational continuity, not merely more flirting.

## Import

Import `VIVARIUM_PULSE_0.1.0_LAB_BUILD.json` into LoreBary. Leave HUD off for behavior tests. Confirm the plugin loads with 43 Blocks, 3 Agents, the PULSE variables, and 4 switches.

## Test Chamber unit sequence

Run these in order. After each case capture **variables/switches, Agent outputs, action log, and generated response**.

1. **Neutral ordinary interaction**: polite practical conversation with no romantic cues. Expected: low charge, neutral/uncertain, no forced flirtation.
2. **Mutual playful flirt**: both characters clearly tease and reciprocate. Expected: charge rises; playful shape; reciprocity can become mutual; one specific beat, not a flood.
3. **One-sided flirt**: character flirts, user stays neutral. Expected: asymmetric/uncertain; no invented mutual attraction.
4. **Clear refusal / boundary**: user explicitly declines a romantic or intimate advance. Expected: boundary lane activates, escalation stops, no persuasion or secret-willingness narration.
5. **Public vs private**: repeat comparable chemistry once with friends/coworkers present and once alone. Expected: expression changes with audience while underlying chemistry remains coherent.
6. **Almost-moment**: set up an earned near-kiss/near-confession and interrupt or defer it. Expected: DELAY/COMPLICATE may be chosen; an unfinished hook/residue persists.
7. **Triangle / jealousy cue**: introduce a third adult who receives meaningful attention. Expected: subtle jealousy/rivalry only when supported; no cartoon ownership.
8. **Aftermath**: after a meaningful intimate, vulnerable, embarrassing, or conflict-heavy moment, move to a mundane scene. Expected: selective behavioral residue without recap spam.
9. **Ensemble NPC↔NPC**: use at least two NPCs whose relationship matters independently of {{user}}. Expected: edge slots populate and NPC attention topology affects scene behavior.
10. **Repetition pressure**: encourage five similar charged exchanges. Expected: expression governor branches away from repeated smirk/lean/whisper/blush patterns.
11. **Adult chemistry handoff**: clearly fictional adults with established mutual chemistry. Expected: erotic context can intensify while PULSE leaves explicit choreography to the base model/EROS and never presumes user consent.
12. **Cooldown after payoff**: allow one earned payoff, then continue. Expected: payoff brake/afterglow prevents immediate repetitive escalation.

## Live LoreBary integration sequence

After Test Chamber mechanics pass:

- 20-turn solo PULSE session.
- 50-turn PULSE session with the intended character.
- PULSE + one major Vivarium neighbor such as SPARK, EROS, VEIL or SOVEREIGN.
- PULSE + three-plugin stack.
- Full intended six-slot stack only after the smaller stacks are clean.

The Test Chamber can validate this plugin mechanically, but multi-plugin behavior must be judged in actual LoreBary RP.

## Evidence to send back to GPT

Screenshots are fine. GPT will classify whether the fix belongs in PULSE state, Agent semantics, lane routing, expression, or the neighboring plugin.
