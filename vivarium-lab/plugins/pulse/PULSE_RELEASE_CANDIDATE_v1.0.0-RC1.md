# VIVARIUM PULSE 1.0.0-RC1

## Status

Release candidate built from live LoreBary character-trial evidence using Lainey, Romy, and Mika. This is release-level architecture but is not yet promoted to stable `1.0.0` until the targeted LoreBary regression packet passes.

## Live defect addressed

Across three different character dynamics, PULSE showed the same structural weakness: **Frame Fixation / Salience Lock**. It could correctly identify the important interpersonal thesis, then over-foreground it instead of accepting answers, letting the frame become background truth, and moving the scene forward.

Observed forms:
- Lainey: control / submission / being-seen frame over-reinforcement after the human player introduced it.
- Romy: chaos / wanted-vs-entertaining insecurity becoming a recurring semantic center.
- Mika: repeated artist-vs-commodity cross-examination after Cam had already clarified the composition critique.

## RC1 architecture changes

- Semantic Frame Lifecycle: stable frame key, summary, status, age, evidence hits, saturation, resolution evidence, and branch pressure.
- Question-Closure Law: clear player answers are accepted as evidence unless later behavior genuinely contradicts them.
- Frame Budget: normally no more than two consecutive assistant replies foreground the same central interpersonal thesis unless the player materially reopens it.
- New deterministic Frame Arbiter block: forces branching after resolution, saturation, aging, strong semantic repetition, or stagnation.
- Auditor now scores frame repetition, subtext leakage, forward motion, and user-authorship violations.
- Subtext Opacity: PULSE keeps rich semantic interpretation private and prefers behavior / timing / dialogue / consequence over narrator telemetry.
- Player Authorship Hard Rule: the human exclusively authors `{{user}}`; PULSE may react to supplied actions but may not invent additional voluntary player behavior or private state.
- Sexual-Topic Firewall: sexual subject matter alone does not create interpersonal erotic chemistry.
- Forward motion does not need to escalate chemistry; it may be practical, social, comic, environmental, intimate, conflictual, or ordinary.
