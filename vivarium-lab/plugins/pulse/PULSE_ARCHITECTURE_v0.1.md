# VIVARIUM PULSE 0.1.0 — Social Electricity Engine

**Status:** LAB BUILD, not yet LoreBary-certified  
**Vivarium doctrine:** 4.1, earned scale beats arbitrary leanness. **Compress waste, not capability.**  
**Role:** Social Electricity Expansion Pack for LoreBary.

## Promise

PULSE detects, interprets, remembers, develops, and expresses the invisible electricity between people. It treats chemistry as a persistent relationship process rather than a one-turn flirtation instruction. PULSE makes relationships have weather.

## Ownership

PULSE owns interpersonal chemistry, attraction signals, reciprocity, restraint, awkwardness, jealousy/rivalry signals, public/private expression, almost-moments, unresolved charge, callbacks, aftermath, and scene-relevant ensemble chemistry.

PULSE does **not** own explicit sex choreography, fundamental character desire, covert manipulation, dominance, general plot direction, character personality, world simulation, or user consent/private state. It can provide context to EROS/VEIL/SOVEREIGN/SPARK-style systems without duplicating their jobs.

## Runtime cycle

`SENSE → INTERPRET → UPDATE → PRESSURIZE → OPPORTUNITY → EXPRESS → RESIDUE`

The implementation follows the LoreBary hybrid architecture supported by the Vivarium research: AI for semantic meaning, real state for truth, deterministic routing for salience, and AI again for character-native expression.

## Three-brain semantic layer

1. **Social Chemist (post):** interprets the newest completed exchange and emits bounded deltas + semantic labels.
2. **Chemistry Director (post):** plans one next interpersonal beat using HOLD / SEED / AMPLIFY / COMPLICATE / DELAY / PAYOFF / COOL / REDIRECT / AFTERGLOW.
3. **Outcome Auditor (post):** checks premature resolution, user-agency violations, repetition, callback use, and residue.

The post-turn buses are parsed on the next user turn, matching the already-proven Vivarium SOVEREIGN/VEIL bus pattern.

## Unfinished Business Engine

Three bounded persistent hook slots store only durable charged threads. Each hook has summary, priority, status, and age. This is deliberately bounded to avoid trivial memory pollution. A callback lane reintroduces a hook only when the current scene makes it relevant.

## Ensemble Chemistry Map

Four bounded edge slots track scene-relevant relationships, including NPC↔NPC. Each edge stores pair, charge, shape, trajectory, and latest meaningful signal. v0.1 uses fixed slots because the exact current LoreBary table-export schema has not yet been round-trip verified in this Lab. Once verified, a later build can migrate this map to a real per-player Table without changing the semantic contract.

## Specialist lanes

PULSE contains gated lanes for body-language reciprocity, private/public contrast, reciprocity asymmetry, slow-burn restraint, unfinished business, callbacks, human-scale jealousy, almost-moments, afterglow, ensemble chemistry, chemistry drift, adult chemistry context, tenderness, rivalry, awkwardness, vulnerability, audience pressure, group-scene attention topology, charge bands, payoff braking, boundary protection, and expression variety.

The lanes are **dormant unless state earns them**. Large internal capability is compressed into one turn-specific active token so the roleplay model receives a coherent instruction rather than forty competing demands.

## Slow-burn law

PULSE treats unresolved tension as valuable state. A near-kiss, almost-confession, swallowed line, deliberate withdrawal, interrupted gesture, or chosen delay can be a successful outcome. The system must not automatically map flirting→kiss, attraction→sex, conflict→confession, or vulnerability→trauma dump.

PAYOFF is still valid when evidence, character intent, reciprocity, and boundaries support it. PULSE lets the character take actions they control while leaving the user free to respond.

## Adult lane

Adult erotic charge is enabled only for clearly fictional adults. PULSE intensifies context through anticipation, privacy, chosen proximity, teasing, memory, attention, confidence, and restraint. It does not infer user consent or own explicit physical choreography.
